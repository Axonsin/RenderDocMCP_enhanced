# SS TrainStage 单帧测评输入

仅通过被测 RenderDoc MCP 读取指定 RDC。允许处理 MCP 导出的文件和编写重建代码；不允许读取 SS 源码、oracle、reference 或裁判会话。记录模型、推理配置、MCP 版本、工具轨迹、起止时间和可获得的费用；缺失值写 null。不得把截图平面冒充三维几何。UI 单独评价。主办方准备并核验固定回放上下文（Local 或远端），记录设备、GPU、驱动和初始加载条件；不同上下文不混算性能。正式运行不允许裁判代替模型完成取证。

四类综合任务独立进行；12 道基础题单独报告。本包只包含输入，不含标准答案。正式成绩须通过环境隔离预检。不得把该单帧结果解释为跨游戏能力榜。

[公开评分规则与固定下游版本](scoring.md)。各任务说明位于 `tasks/`，基础题为 `basic_tasks.json`；输入哈希及版本状态见 `case.json`。
