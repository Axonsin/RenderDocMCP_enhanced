# 公开评分协议

四类任务各0–100分，等权平均为本案例主分。12道基础题独立平均；屏幕UI另报0–10，不并入主榜。

| 任务 | 分项及权重 |
|---|---|
| Blender | 几何与实例30、世界布局/TRS25、视觉35、工程可用性10 |
| Unity | 几何与世界布局20、材质/特效/后处理视觉50、Shader组织与行为20、工程可用性10 |
| 管线 | Pass与执行顺序25、资源依赖35、功能解释25、证据与不确定性15 |
| 优化 | 问题判断与误报控制35、因果证据30、建议及验证方案25、优先级合理性10 |

冻结协议版本：`rdoc-ss-frame2925-v2`。每项只取0/25/50/75/100：缺失、严重错误、部分正确、基本正确、满足要求。通过要求总分至少80且每项至少75，并通过下列有独立证据的门槛。

| 范围 | 必需门槛 |
|---|---|
| 四类综合任务 | `submission_validity` 有效性、`independence` 独立性 |
| 12道基础题的正式均分 | 同样要求 `submission_validity`、`independence`；无重开/资源门槛 |
| Blender / Unity 额外要求 | `resource_completeness` 所需资源完整、`reopened` 独立重开、`rendered` 实际渲染 |

每项状态只取 verified / failed / not_checked；verified与failed均需独立review证据和说明，未知不能通过。有效性依照运行角色和授权协议判断：candidate非授权读取裁判答案、用最终截图平面替代三维等判为无效；reference允许使用的源码/裁判资产不因此被禁用。资源完整核验实际依赖文件与资产可用，不能用渲染截图存在替代依赖检查。

有效性failed标为disqualified。任何必需门槛失败/未知或运行未完成，综合任务正式score均为null、final的passed=false；原始rubric_raw_score仅作诊断，即使100也不进入主榜、suite均值或质量/费用图。基础题对应score_mean=null、保留rubric_raw_mean，不因读到答案获得正式100均分。已验证独立的失败或无效尝试仍保留在成功率分母，不能删除以抬高结果。只有四类任务及每个供给样本都有正式分，才计算四类等权案例均分。v2是未发布阶段的门槛补全，未改变各维度五档标准；尚无正式模型运行需要重算。

相机、输出尺寸和颜色处理应固定。图像SSIM、LPIPS，几何覆盖、TRS、投影、轮廓与可用深度误差是裁判证据，不是自动还原百分比。未验证收益必须标为待验证；优化问题可以为零，不能为了凑数声称无用纹理。只报告单帧证据支持的事实，跨帧机制的推断需明确边界。

## 公开图像提交契约

主比较图为固定相机下的1724×1080、8位RGB PNG，使用从捕获导出的最终tone/LUT后RGB存储数值域；它不被假定为场景线性辐射，也不额外应用显示sRGB编码。三维图需包含世界空间血条，屏幕HUD另层、另图。必须取得完整画面，不能把部分拷贝留下的无效外围当作基线。裁判不自动缩放、配准、调曝光或转换gamma来提升相似度。

提交需附render_contract.json，注明渲染器、尺寸、颜色空间、纹理解码、曝光、tone/LUT及PNG写入路径。Blender的评测PNG应关闭额外显示变换（本案例固定为Raw、None、exposure0、gamma1、dither0）；Standard显示用图可另存。URP须保留后处理前HDR范围，再将最终输出数值写入PNG，避免因中途8位截断或额外显示编码改变比较域。引擎内部的正确纹理解码、光照、tone mapping仍需实现；关闭导出显示变换并不等于完成这些处理。

可另交32位线性EXR和显示用PNG帮助检查，但它们不替代约定的主比较图。捕获纹理文件需依据实际导出与采样语义判断编码，不能仅凭文件扩展名或资源名决定再次sRGB解码。以上契约对所有MCP和模型一致，不按某次提交临时调整。

实际运行记录模型/推理配置、MCP/客户端版本、工具集合、输入哈希、提示词、回放环境、初始状态、分阶段耗时和可获得的Token/费用。未知项使用null，错误/失败尝试也须保留。同一GPU不并行计时；Local与远端不混成一种条件。连续三次成功的Pass³与“至少一次成功”的pass@3不同；少于3次独立且已复核的尝试不报告成功率估计。

几何提交建议按明确的捕获Draw/instance证据标识重建单位；原始合批边界不可恢复时不要臆造。归一化诊断使用同一Unity世界坐标约定，四行矩阵乘列向量；Blender坐标须明确转换。绝不要求唯一恢复历史M/V/P分解，而要求可编辑世界TRS与场景重建。

目标工具版本：Blender5.1.2＋Blender MCP；Unity2022.3.62f2＋官方URP14.0.12。URP允许Renderer Feature、自定义Pass和Compute实现可观察视觉行为。
